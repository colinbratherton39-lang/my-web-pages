One-time setup: get a Google Client ID
  1. Open Google Cloud Console and create or select a project.
  2. Enable the Google Analytics Admin API and Google Analytics Data API in APIs & Services → Library.
  3. Configure Google Auth Platform / OAuth consent screen, adding yourself as a test user if the app is in testing mode. Add the https://www.googleapis.com/auth/analytics.readonly scope if prompted.
  4. In Clients / Credentials, create an OAuth client ID of type Web application.
  5. Under Authorized JavaScript origins, add https://colinbratherton39-lang.github.io (no path, no trailing slash). For local testing also add http://localhost:8000 if you use that address.
  6. Copy the Client ID into the box above. Host this file on your GitHub Pages site; opening it as a file:// download will not support Google sign-in.

OAuth configuration is required by Google. The client ID is public, but never put a client secret in an HTML page.
